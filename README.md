# Кинотеатр «Пиксель»: охота на баги

Вы — команда разработчиков, получившая чужой проект с ошибками. Исправьте поведение программы, **не переписывая её с нуля**.

## Запуск

Требуется Python 3.10+. Интернет и сторонние библиотеки не нужны.

```bash
python main.py
```

При первом запуске файл `bookings.json` может отсутствовать: программа должна создать его при первой успешной брони.

## Правила предметной области

- В каждом сеансе места пронумерованы от 1 до количества мест включительно.
- Одно место одного сеанса нельзя забронировать дважды.
- Имя посетителя не может состоять только из пробелов.
- Возраст посетителя — целое число от 0 до 120 включительно.
- Дети **до 12 лет включительно** получают скидку 50%, посетители **от 60 лет** — 20%.
- Промокод `PIXEL10` даёт ещё 10% скидки, которая применяется **после возрастной скидки**.
- Бронирование получает уникальный положительный номер; после отмены старый номер нельзя выдавать снова.
- Отмена освобождает место.
- Список бронирований должен сохраняться после перезапуска.
- Пункт «Выручка» в этой учебной модели показывает сумму действующих бронирований (не бухгалтерскую выручку).
- Если файл данных повреждён, программа должна сообщить о проблеме **и не перезаписывать повреждённый файл молча**.

## Обязательные проверки

1. Забронируйте место 1 на сеанс 1; повторите попытку для того же места.
2. Забронируйте место 1 на сеанс 2: это должно быть разрешено.
3. Отмените бронь и забронируйте освободившееся место.
4. Проверьте возраст 12, 13, 60, 121 и -1.
5. Проверьте промокод `pixel10` и комбинацию возрастной скидки с промокодом.
6. Проверьте пустое имя и имя из пробелов.
7. Проверьте нулевой, отрицательный и превышающий вместимость номер места.
8. Создайте несколько броней, отмените не последнюю и создайте новую. Проверьте уникальность ID.
9. Перезапустите программу и убедитесь, что брони сохранились.
10. Проверьте реакцию на неверный ввод в меню и числовых полях.
